# Week 8 — Day 1: Project Setup & Package Installation

## Topics Covered
- **Project Initialization:** Used `npm init -y` to create `package.json`.
- **Express:** Installed Express to build a Node.js web server.
- **dotenv:** Installed dotenv to manage environment variables using a `.env` file.
- **Nodemon:** Installed nodemon as a development dependency to automatically restart the server when code changes.

## Commands Used
```bash
npm init -y
npm install express
npm install dotenv
npm install -D nodemon
```

## Key Learning
Learned how to initialize a Node.js project and install the packages required for backend development using npm.
