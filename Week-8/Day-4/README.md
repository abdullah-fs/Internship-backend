# Week 8 — Day 4: Understanding REST APIs

## Topics Covered
- **REST API:** Understood how frontend and backend communicate through APIs.
- **HTTP Methods:**
  - `GET` — Retrieve data.
  - `POST` — Create new data.
  - `PUT` — Update existing data.
  - `DELETE` — Remove data.
- **HTTP Status Codes:**
  - `200 OK` — Request successful.
  - `201 Created` — Resource created successfully.
  - `400 Bad Request` — Invalid request.
  - `404 Not Found` — Resource not found.
  - `500 Internal Server Error` — Server-side error.
- **Request & Response:** Learned how the frontend sends requests and receives responses from the backend.
- **Request Structure:**
  - Params — Identify a specific resource, e.g. `/api/tasks/5`.
  - Query — Filter or search data, e.g. `/api/tasks?completed=true`.
  - Body — Send data when creating or updating a resource.

## Key Learning
REST APIs use HTTP methods, request/response structures, and status codes to manage communication between frontend and backend.
